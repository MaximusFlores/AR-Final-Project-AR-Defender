# AR Video Game Demo

## Overview

An augmented reality (AR) video game demo developed using Unity and the Vuforia Engine. The project explores the integration of augmented reality with interactive gameplay, allowing players to interact with virtual objects within a real-world environment through a mobile device.

The game uses image targets to establish the AR environment and incorporates interactive objects and gameplay elements to create an intriguing experience.

## Technologies Used

- **Game Engine:** Unity 6.2
- **Programming Language:** C#
- **AR Framework:** Vuforia Engine
- **Platform:** Android

## Features

- **Image Target Tracking:** Uses Vuforia image targets to recognize and establish augmented reality environments.
- **AR Object Interaction:** Allows players to use an image target attached to a real object to aim their attacks and defense.
- **Mobile Deployment:** Designed and tested for Android mobile devices.

## Installation and Setup

1. Clone or download this repository.
2. Open Unity Hub.
3. Select **Add Project** and navigate to the downloaded project folder.
4. Open the project using the appropriate Unity version.
5. Ensure the Vuforia Engine package is properly installed and configured.
6. Configure the appropriate Vuforia license key and image targets.
7. Build and deploy the project to a compatible Android device.

## Development Notes

This project was developed to explore augmented reality application development and interactive gameplay using Unity and Vuforia. Development involved implementing object interactions, configuring image target tracking, and adapting the experience for mobile deployment.
